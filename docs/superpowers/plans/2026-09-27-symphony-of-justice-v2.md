# Symphony of Justice V2 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current static V1 presentation with a production-ready React + TypeScript + Vite V2 that preserves the current GitHub Pages URL, project dossiers, art classification, and archive while adding the approved interactive game-system experiences.

**Architecture:** Use a hash-routed React SPA with route-level lazy loading, custom CSS design tokens, structured TypeScript game/demo data, pure system modules for calculations, and JSON dossier/art manifests generated by the existing Python tooling. GitHub Actions builds `dist/` and deploys it from the same repository; the old V1 runtime is archived rather than reused.

**Tech Stack:** React 19, TypeScript, Vite, React Router, Motion for React, Vitest, React Testing Library, CSS custom properties, LocalStorage, existing Python build tools, GitHub Actions / Pages.

**Spec:** `docs/superpowers/specs/2026-09-27-symphony-of-justice-v2-design.md`

## Global Constraints

- Keep the current GitHub repository and GitHub Pages root URL unchanged.
- Use hash-based routes such as `/#/world` and `/#/characters/kael`.
- Preserve all 31 dossiers and the existing art classification/policy.
- Official art and concept/reference art must remain clearly distinct; references render `Concept Reference · Not Final Game Art`.
- Runtime V2 does not depend on a backend, login, paid API, or real-money functionality.
- Demo-only stats/mechanics live under `src/data/demo/` or carry `demo: true`.
- No autoplay audio, full-page canvas, or required background video.
- Support keyboard navigation, visible focus, meaningful alt text, reduced motion, and responsive mobile layouts.
- Namespace persisted browser state under `soj.v2.*` and recover safely from invalid/outdated stored data.
- Do not include working DOCX source files in `dist/` unless explicitly public.

## Review Focus

1. **Unknown IDs / malformed routes:** render branded contextual Not Found states without crashing.
2. **Corrupt/outdated LocalStorage:** reset only the affected feature state to defaults and keep the rest of the app usable.
3. **Missing/broken image assets:** render a named fallback while preserving card/layout dimensions.
4. **Empty or zero-result filters/search:** show helpful empty states with reset/navigation actions rather than blank panels.
5. **Reduced-motion/mobile contexts:** interactive modules remain usable without relying on animation, hover, or tiny desktop-only layouts.
