# Art Classification Policy

The website intentionally separates two visual classes.

## Official / named project material

Named character, enemy and location files are treated as project art for presentation purposes and appear without the reference warning.

## Concept / reference material

A file is classified as reference material when it is stored in a Concept/Concept Art folder or when its filename is primarily an identification code rather than a project-facing name.

The public UI adds a visible **Concept · reference only** stamp and describes these images as non-production visual references. They should not be treated as proof of final ownership or licensing.

Before commercial launch, replace every reference image with an owned or properly licensed asset and re-run the art manifest build.
